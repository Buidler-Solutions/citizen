# Changelog

All notable changes to `@citizen-protocol/typescript-sdk` are tracked here.

## 0.1.0 - 2026-04-23

- TypeScript-first SDK baseline with generated declaration output and dual ESM/CJS artifacts.
- Public API report tooling and release-gate automation (`api:report`, `api:check`, `release:check`).
- Live builder smoke path (`smoke:live`) that exercises signed envelope submission and receipt polling against a running node.
- Changelog automation scripts (`changelog:generate`, `changelog:check`) added for release readiness.
